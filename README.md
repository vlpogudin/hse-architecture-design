# hse-architecture-design

Погудин В.А., РИС-23-1

**Вариант №16**

Гиганту электроники нужна новая система сообщений о неполадках для своих ИТ-консультантов, работающих с клиентами, в магазинах по всей стране.

**Пользователи**: тысячи покупателей, сотни консультантов, сотни сотрудников магазинов.

**Требования:**
- Заявки на неисправности могут быть введены администраторами колл-центра, сотрудниками магазина или покупателями онлайн.
- Заявки направляются к соответствующему консультанту в зависимости от местоположения, доступности и навыков.
- Консультантам необходимо только мобильное устройство
- Клиенты проходят оценку консультанта после обслуживания
- Консультант отслеживает выполненную работу в записях клиентов для дальнейшего использования.

Дополнительный контекст:
- время безотказной работы имеет решающее значение для репутации компании
- производительность сайта должна корректно снижаться при большой нагрузке
- хорошая маршрутизация запросов имеет решающее значение для получения прибыли
